## 구조화 범위

주요 전형규칙 22개, 일정 14개, 설명 섹션 25개를 동일 manifest에서 적재했다. 원문 PDF SHA-256, 학년도, 대학, 캠퍼스, 문서 단계 및 근거 페이지를 저장한다. 모든 학과·환산표를 완전히 전사한 데이터는 아니다. 모집인원은 미공개 상태로 표시하며 0명 행을 만들지 않는다.

## 답변 정책

- 최종 요강이 확보되지 않고 기본계획이 있으면 해당 대학 기본계획 기준이며 변경될 수 있음을 표시한다.
- 기본계획에서 근거를 찾지 못하면 현재 확보한 근거에서 확인하지 못했다고 안내한다. 일부만 구조화했으므로 검색 실패를 원문에 정보가 없다는 단정으로 바꾸지 않는다.
- 둘 다 없으면 서비스에 자료가 확보·검증되지 않았다고 안내하고 대학 입학처 확인을 권한다. 미보유와 실제 미공개를 구분한다.
- 전형 구조화 조회가 비어 있는 개별 조회·설명 질문은 설명 섹션과 전형규칙의 의미 검색으로 재시도한다.
- 인천 공인영어는 자체 필기로 분류하지 않는다. 경상 수의·약학 1단계 필기50점/총70점을 필기50%로 저장하지 않는다.

## 최종 모집요강 교체

기존 `ingest-transfer-manifest.mjs`로 같은 대학·캠퍼스·학년도의 `최종 모집요강` 또는 `모집요강`을 적재한다. 새 문서 임베딩과 활성화 성공 뒤, 그 범위의 기본계획·주요사항 문서를 삭제한다. 연결된 지식 단위 및 벡터는 FK CASCADE로 삭제된다. 다른 학년도·대학·캠퍼스는 대상이 아니다. 최종 문서 활성 상태에서 기본계획으로 역행하는 적재는 차단한다.

원본 PDF와 로컬 manifest는 삭제하지 않아 재적재로 복구할 수 있다. 새 문서 활성화와 후속 정리는 여러 요청으로 실행되므로 중간 정리 실패 시 로그를 확인하고 재실행해야 한다. 동일 범위 적재를 동시에 실행하지 않는다. 대학 사이트의 신규 공개를 자동 감지·수집하는 기능은 포함되지 않는다.

## 검증 및 배포

정책·manifest·교체 조건 테스트 6개, 기존 오프라인 평가 12개, TypeScript 검사 및 수정 파일 lint를 실행한다. 운영 DB 데이터는 적재 완료. 답변 로직 변경은 애플리케이션 배포 후 운영에 반영되며, 이번 작업에서 앱 배포는 실행하지 않는다. 실제 최종 모집요강을 넣어 운영 데이터를 삭제하는 검증은 하지 않는다.
